Dravex is fast PvP built on modular cores. A core is the loadout: weapon behavior, abilities, grenade, crush, kill, sound, and UI tint.

## loop
- Select or load a core
- Primary fire (auto-charge)
- Manage four-shot power
- Crush, grenade, or combine
- Beacon for reposition
- Eliminate

## goals
- Distinct core identities
- Readable VFX under fire
- Skill expression (when to crush / throw / fold)
- High visual quality without server load
